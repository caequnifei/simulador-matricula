# Simulador de Matrícula - Engenharia Química UNIFEI

Aplicativo em Streamlit para simulação de matrícula do curso de Engenharia Química da UNIFEI.

## Arquivo principal

`simulador_matricula_EQI.py`

## Executar localmente

```bash
python -m pip install -r requirements.txt
python -m streamlit run simulador_matricula_EQI.py
```

## Publicação no Streamlit Community Cloud

Use:
- Branch: `main`
- Main file path: `simulador_matricula_EQI.py`

A matriz oficial deve sempre ser conferida no SIGAA/UNIFEI.
